# تطبيق التارزي — مشروع بناء APK

هذا المشروع يغلّف ملف الويب الأصلي `index.html` داخل تطبيق Android باستخدام Capacitor. لم يتم تعديل واجهة التطبيق أو منطقها.

- اسم التطبيق: **التارزي**
- معرّف الحزمة: `com.tailor.app`
- نوع الملف الناتج: **Debug APK** قابل للتثبيت للاختبار
- التخزين: يعتمد التطبيق الأصلي على `localStorage`؛ لا تحذف التطبيق أو بياناته قبل نسخ بياناتك المهمة.

## البناء

يعمل GitHub Actions على خادمه لبناء APK دون الحاجة إلى Android Studio على جهازك.

1. افتح تبويب **Actions**.
2. اختر **Build التارزي APK** ثم **Run workflow**.
3. بعد نجاح التشغيل، افتح التشغيل ونزّل `al-tarzi-debug-apk` من قسم Artifacts.
4. فك ضغط الأرشيف وثبّت `app-debug.apk` على هاتف Android.

هذا إصدار Debug للاختبار وليس إصدارًا موقّعًا للنشر التجاري. يجب اختبار التطبيق على الهاتف قبل الاعتماد عليه.
